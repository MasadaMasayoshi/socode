# 使えない機能の整理（v.28）

「AIは使わない」方針（v.26–v.28）に合わせて、画面から呼べなくなっていた機能のコードを消しました。

## 消したもの
- AIで分類を評価（評価ダイアログ一式・適用・改善点ファイル）
- 不足情報のAI推定／S/O矛盾のAI確認／看護診断候補のAI／経時変化サマリーのAI／看護計画のAI作成
- 充足・未充足のAI評価、自分のアセスメントへのAI助言
- 看護計画のAI評価（1件・全計画）
- ボタン1つで看護計画まで進める処理
- 関連図のAI作成・矢印の説明・間の過程のAI提案とその指示文／読み取り
- 管理画面の「AIで要約」
- 関連するテスト（上記の機能だけを確かめていたもの）

## 残したもの
- 写真の文字起こし（OCR）と、APIキーの設定・接続確認（requestGemini / callGeminiAI / requireApiKey）
- 検査値の評価（ルールだけで動く。evaluateLabValuesAI の名前は残している）
- 保存済みの古いAI結果の表示（読み込みのみ）

## 確認
`npm run test:quiet` で、いつもの失敗（サーバー側の9件）以外に失敗が無いことを確認。
