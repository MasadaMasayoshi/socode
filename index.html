 このブラウザで行った修正だけの記録です（新しい300件まで）。全員の修正の記録は「事例ログ」で見られます。

        

        
      


      
      

        

          
          
          
        

        
 全員が行った修正の記録です（サーバーに保存。このブラウザだけの記録は「変更履歴」）。

        

        

      


      
      

        

          
          
        

        

           同じ文言への同じ修正（分類・タグ）が2回以上繰り返されたものを、確立度（合計回数）の高い順に表示します。得票の多い上位のみがAIへの指示に反映されます（閲覧のみで削除機能はありません）。
        

        

      


      
      

        

          
          
        

        

           全患者のカードで、手で外したタグ・手で付けたタグ・S/Oの手直しを数えています（削除したカードは数えられません）。2回以上のものは赤で表示します。「このキーワードでは付けない」を押すと、次の分類から反映されます。
        

        

      


      
      

        

          
          
          
          
          
        

        

          

             「付ける」：文章にキーワードを含むとき、選んだタグを付けます（14項目の既定のキーワードに無い語や、「生殖」のように入れる項目を決めておきたい情報に）。「付けない」：既定のキーワードで付くタグを、そのキーワードでは付けないようにします。全員に共有され、次に「分類開始」したときから反映されます。
          

          
        

        

      


      
      

        

          
          
        

        

           情報カードの「報告」ボタンから送られた内容の一覧です（閲覧のみで削除機能はありません）。同じ人がページを閉じるまでに送った複数件は1つの投稿としてまとめて表示されます。
        

        

        

        

        

      


      
      

        

          

            
基準ノート本体

            
              
              
            
          

          

             ルールに基づく分類・検査値評価と、手動の看護過程の検証に利用する基準ノートです。内容は全利用者・全端末に共有されます。これまでの学習データ（S/O・タグの修正）から繰り返し確認された傾向は、保存内容と自動的に統合されてAIへの指示に反映されるため、ここに書き足す必要はありません。
          

          
          

            サーバーに保存されていた古い版の代わりに、下の「統合版」を使っています。書き足した基準や追加の分類基準も入れるときは「分類基準を統合」を押してください。
            
          

          
        

        

          
追加の分類基準（現場からの要望）

          

             基準ノート本体とは別に、コードを直接編集せずに追加できる分類ルールです。内容は全利用者・全端末に共有されます。
          

          

          

            
            
          

        


        
        

          
参照元リンク（NotebookLM等）

          

             NotebookLMには個人が使える公開APIが無く、リンクを貼るだけでの内容の自動取得はできません。名前とリンクを登録し、内容はNotebookLM等からコピーしてここに貼り付けてください（貼り付けた内容が、基準ノート本体・追加の分類基準と同様にAIの分類に反映されます。内容が未貼付でもリンク自体は一覧に残ります）。内容は全利用者・全端末に共有されます。
          

          

          

            

              
              
            

            

              
              
            

          

        

      


      
      

        

          
          
          
        

        

           タブを閉じるたびに、その時点のカルテ内容がそのまま記録されます（閲覧のみで削除機能はありません）。「編集した人」はログイン機能が無いため区別できず、タブごとの識別子の一部のみを表示します。行をクリックすると、その時点のカード内容を展開して確認できます。「今すぐ同期して保存」ボタンで、5分おきの定期バックアップを待たずに今の状態を保存できます。
        

        

      


      

        

          
          学習データは、サーバーの学習専用ファイル（全員で共有）とこのブラウザの両方に自動で保存されます。書き出し・読み込み・消去は「現在の学習内容」タブにあります。
        

      

    

  


  
  
  

    

      

        
 薬の情報

        
      

      
      

      

      
 各薬の添付文書の主な内容を、看護で観ることを中心に短くまとめた参考です（用量・禁忌・相互作用のすべてではありません）。必ず最新の添付文書と、医師・薬剤師の指示で確かめてください。見つからない薬は PMDA 医療用医薬品の添付文書情報 で調べられます。

           設定
        

        
      

      

        
        
        

        

          
          入力中のキーで短い依頼を1回送ります
        

        

        
        
        
「混雑しています」が続くときは「軽量（Flash-Lite）」も試してください。応答の速さ・混み具合はGoogle側の状況で変わり、どのモデルでも保証はできません。

        
写真の文字起こし（OCR）のみに使用します。AIによる分類・文章生成・関連図生成・看護計画生成・評価は使用しません（このブラウザだけに保存）。HTMLファイルを直接開いて使っても動きます。ただし、ブラウザの種類や開き方（ファイルから／サーバーから）が変わると保存場所も別になるため、もう一度入力が必要です。

      

      
      

        
        
        
AIに送る前に、ここの語句と、氏名・学籍番号・病院名・電話番号・「〇〇さん」などの個人情報らしい語句を自動で〈伏せ字〉にします。AIの答えは元の語句に戻して表示します。ここの語句はこのブラウザだけに保存されます。

     操作方法
    
        
      
    
      
    
        
        
        
        
        
      
    
      
    
        
    
          
      
            
    1. 情報収集：左の「記録メモ」に記録を貼り付け（写真はドラッグ＆ドロップで文字起こし）、「分類開始」で情報カードに分けます（S／O とヘンダーソンの14項目のタグが付きます）。分類ボードでカードを選んで S/O・タグ・本文を手直しし、未分類・タグなしが無くなれば済みです。「変更点の比較」で直した所を確かめられます。
      2. 
            
    2. アセスメント：「総合アセスメント表」で項目ごとにカードを入院前／入院後に分け、「自分のアセスメント」を書いて根拠のカードを選びます。不足情報は確認したら「確認済み」にします。
      3. 
            
    3. 看護計画：「看護計画」タブで目標・OP/TP/EPを書き、毎日の実施・評価を記録します。
      4. 
            
    4. 書き出し：右上の「提出用に書き出し」で、SOAP形式・実習記録の様式を選んで書き出します。
      5. 
          
    
        
    
        
    
          
      
            
    • 選ぶ：カードを押すと選ばれ、元の文章の該当箇所に印が付きます。もう一度押すと外れます。
      • 
            
    • 複数選ぶ：カード左上のチェックボックスを押します（スマホ・タブレットでも使えます）。Ctrl（Mac は ⌘）を押しながらクリックでも選べます。選ぶと画面の下に一括操作の帯が出ます（S/O の変更・タグ・統合・書き出し）。
      • 
            
    • タグ：カードを選んで数字キー 1〜14 でタグを付けます。「＋タグ」から選ぶこともできます。タグの × で外します。
      • 
            
    • S/O を変える：カードを S・O の列へドラッグするか、カードの「︙」→「Sに移す／Oに移す」。
      • 
            
    • 編集・不要・削除・報告：カードの「︙」メニューにまとめています。
      • 
            
    • 未分類・不要：未分類のカードはS・Oの下の「未分類」の枠、不要にしたカードはいちばん下の「不必要な情報」を開くと見られます。
      • 
          
    
        
    
        
    
          
      
            
    • 上の 1〜14 のボタン（または ← → キー）で項目を切り替えます。「すべて」で14項目を一覧にします。
      • 
            
    • 項目を選ぶと、中央に「入院前」「入院後」、上に「未分類」、下に「不足情報」が出ます。カードは枠の間でドラッグするか、カードの「前・後・欠」ボタンで移します。
      • 
            
    • 「自分のアセスメント」に情報の解釈・考えられる原因・今後の見通しを書き、根拠のカードを選びます。「確定」すると版として残り、あとで情報が変わると再評価を知らせます。
      • 
            
    • 不足情報のカードの「未確認」ボタンで、確認した内容と結果を記録できます。
      • 
          
    
        
    
        
    
          
      
            
    • 1〜9：カードを1枚だけ選んでいるとき、その番号のタグを付ける（分類ボード）。10〜14は2桁を続けて押します（例：12）。
      • 
            
    • Esc：選択を外す／開いている画面を閉じる／全画面入力を戻す
      • 
            
    • ← →：総合アセスメント表の項目を切り替える
      • 
            
    • Tab：ボタン・入力欄を順に移動。入力欄で文字を打っている間は、数字キーや矢印キーの操作は働きません。
      • 
          
    
        
    
        
    
          
      
            
    • 書いた内容はまずこのブラウザに保存し、続けて共有先（サーバー）にも保存します。画面右上の表示で状態が分かります：「このブラウザに保存済み」「共有先に保存済み」「共有先への保存に失敗（押すと再送）」。
      • 
            
    • 共有先に保存できないときも、このブラウザには残っています。自動で送り直すほか、表示を押すとすぐ送り直します。
      • 
            
    • AI（Gemini）の機能は、右上の「︙」→「API設定」でキーを入れたときだけ使えます。キーが無くても、分類（AIなし）・手直し・アセスメント・看護計画・書き出しはすべて使えます。
      • 
            
    • 画像OCRの読取結果は必ず原画像と照合してください。画像は送信前に個人を特定できる情報を除いてください。
      •
