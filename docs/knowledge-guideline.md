# 医学知識の取り込みガイドライン

このサイトに医学知識を足すときの決まりです。人（利用者）、Claude、他のAIのどれが作業するときも、この順で行います。

## 1. 目的

- サイトの分類・関連図・看護計画で「判断できなかった点」や「知識が極端に少ない点」を、出典の有無で取捨しない。出典が示されていない知識も取り込み、出典欄は「深層調査 2026-10-15（出典未確認）」のように由来を書く。
- 患者さんの情報は取り込まない。取り込むのは、どの患者にも当てはまる一般的な医学・看護の知識だけ。

## 2. 知識の集め方（サイトが質問する）

1. 分類ボードの「…」メニュー →「知識をリクエスト」でファイルを書き出す。
2. ファイルには、サイトが判断できなかった語・診断・看護問題・看護計画の空欄が、1語1項目でまとめてある（氏名・日付は伏せてある）。
3. 各項目の「回答」と「出典」を埋める。
4. 埋めたファイルをClaudeに渡す（元の患者記録は不要。「記録」欄の文脈で足りる）。

## 3. 回答の書き方（取り込みやすい形）

1項目につき次の5点を、短く書く。

| 欄 | 書き方 | 例 |
|---|---|---|
| 何についての知識か | 用語は1つだけ | 光線過敏症 |
| 内容 | 1〜3文。「誰にでも当てはまる事実」だけ | 紫外線で皮疹が出やすい。日焼け止めや衣服で防ぐ指導が必要。 |
| 関係する14項目 | 番号と理由 | 8（皮膚の保護）、9（環境） |
| 出典 | 書名・版・ページ、または公的ガイドライン名と年 | 〇〇看護学テキスト 第◯版 p.◯ |
| 当てはまる範囲 | 条件があれば書く | SLEなど膠原病の患者で多い |

- 因果は「原因 → 途中の変化 → 結果」の順に書く（関連図に使う）。
- 看護計画向けは、観察（OP）・援助（TP）・教育（EP）に分けて書く。
- 数値の基準は、単位と出典（未確認なら由来の表記）を付ける。出典がないことを理由に見送らない。
- 迷う点は無理に答えず「不明」と書く。不明のまま推測で埋めない。

## 4. サイトに取り込む基準

### 4-1. ガイドラインで定めた種類（そのまま取り込む）

- 症状 → 看護の14項目
- 診断 → 注目する14項目、典型症状、検査所見
- 関連図の仕組み（原因 → 途中の変化 → 結果）
- 看護計画の要点（目標の目安、OP・TP・EP）
- 薬の作用・主な副作用・観察点
- 検査値・バイタルの基準と読み方

### 4-2. 定めた種類以外でも取り込めるもの

回答の中に、4-1に当てはまらなくても役に立つ知識があれば、次の条件をすべて満たすときは取り込む。

1. 出典欄に出典、または由来（調査メモのパス・「出典未確認」の表記）を書く。出典が足りないことを理由に見送らない。
2. 患者個人に関係しない一般的な内容である。
3. 既存の知識・ルールと矛盾しない（矛盾する場合は取り込まず、利用者に確認する）。
4. サイトのどの機能（分類・関連図・看護計画・検査値・観察の確認など）に使えるか説明できる。
5. 取り込んでも既存のテストが通る。

### 4-3. 取り込んだ理由の説明（必須）

4-2で取り込んだものは、毎回、次の4点を報告に書く。理由が書けないものも、由来と効く場所を書いて取り込む（出典がなくても見送らない）。

- 何を取り込んだか（1行）
- なぜ取り込んだか（どんな場面で役に立つか）
- 出典
- どこに効くか（どの画面・どの判断が変わるか）

## 5. 取り込めない・見送るもの

- 出典が古く基準が変わっていると分かっている知識（取り込む場合は見直し予定を早める）
- 患者の氏名・年齢・日付・病院名など個人が特定できる情報
- 特定の1症例にしか当てはまらないルール（その症例の語に合わせたルール）
- 診断・治療を断定する内容（サイトは根拠を示すだけで、診断はしない）
- 既存の知識と矛盾し、どちらが正しいか確認できていないもの

見送ったものは、理由を付けて利用者に返す。出典が足りないことは、見送りの理由にしない。

## 6. 取り込み作業の手順（Claudeが行う）

1. 回答を読み、4-1・4-2・5のどれに当たるか分類する。
2. 患者固有の語・数字を除き、一般的な形にする。
3. ルールにする（症状→項目、診断→項目、関連図の仕組みなど）。
4. 既存ルールとの矛盾を調べる。
5. テスト（分類の基準ケース、タグ未設定の割合、関連テスト）を通す。
6. 公開し、報告する（取り込んだもの・理由・出典・効く場所／見送ったもの・理由）。
7. 次回の「知識をリクエスト」で、同じ項目が減っていることを確かめる。減らなければ、回答が足りなかったので、より具体的に質問し直す。
