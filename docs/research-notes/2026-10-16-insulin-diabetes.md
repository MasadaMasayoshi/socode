# Topic: 「中耳炎」
1. 内容: 中耳炎は中耳部の急性感染症で、感冒後のウイルスや細菌感染によって起こる。特に小児に多く、耳痛・発熱を伴い、鼓膜穿孔時には膿性耳漏を伴うことがある。  
2. ヘンダーソン14項目: 
   - **7 (体温調節):** 感染に伴う発熱があるため、体温や発汗を観察する。  
   - **9 (安全):** 鼓膜穿孔や乳様突起炎などの重篤な合併症の可能性があるため、鼓膜の状態や耳漏の有無を確認する。  
   - **10 (コミュニケーション):** 難聴が起こる可能性があるため、聴力や言語によるコミュニケーション状況を評価する。  
3. 因果: 上気道感染による耳管逆行性の中耳炎発症→中耳に滲出液が貯留（鼓膜膨隆）→耳痛・発熱・耳閉塞感を来す。  
4. 看護: 
   - **OP:** 体温や耳痛の訴え、鼓膜所見（発赤・膨隆・耳漏）を観察・記録し、聴力や言語理解の変化を確認する。  
   - **TP:** NSAIDsなどの鎮痛薬投与で痛みを緩和し、必要時には抗菌薬投与や鼓膜切開排膿を行う。安静・安眠環境を整える。  
   - **EP:** 抗菌薬や鎮痛薬の服薬遵守、耳の清潔保持（入浴時に水が入らないよう注意）などを教育。高熱や耳漏の増悪時には受診するよう指導する。  
5. 出典: 看護roo!（急性中耳炎, 2018）。  
6. 範囲: 急性中耳炎の場合に該当し、滲出性中耳炎や慢性中耳炎、外耳炎・内耳炎など他の耳疾患には当てはまらない。  

# Topic: 「回注射」
1. 内容: 1型糖尿病ではインスリンを皮下注射で自己補充する。ペン型注射器を用い、注射針は毎回新しく交換する。アルコール消毒後に皮膚を直角に速やかに刺入し、薬液をゆっくり注入する。注射針は1回限りで使用後すぐ廃棄する。  
2. ヘンダーソン14項目: 
   - **8 (清潔):** 注射時の皮膚消毒と使用器具の清潔保持が必要。  
   - **9 (安全):** 正確な投与量と手技で誤投与・感染を防ぐ。  
3. 因果: 注射針の使い回しや単位誤りなどミス→インスリン効果の過不足→低血糖または高血糖を招く。  
4. 看護: 
   - **OP:** 血糖値と低血糖の徴候（冷汗・手の震え・動悸など）を観察し、注射部位の皮膚所見を確認する。  
   - **TP:** 注射器具を準備し、目盛りと投与量を確認して正しく投与する。注射針は使い捨てとし、その後速やかに廃棄する。サイトローテーションを行う。  
   - **EP:** 患者・家族に注射手技とサイトローテーションを指導。低血糖時にはブドウ糖摂取などで速やかに対処する方法（冷汗・振戦が出たら糖分補給）を教育。  
5. 出典: 日本糖尿病協会『インスリン自己注射ガイド』(2014), 岸田裕治「インスリンの副作用と注意点」(2026)。  
6. 範囲: インスリン皮下注射に関する知識であり、他の注射や経口療法には適用されない。  

# Topic: 「セルフケア」
1. 内容: セルフケアとは、患者自身がインスリン注射、血糖自己測定、低血糖対処、適切な食事管理など、病気の管理に必要な行為を主体的に行うことである。小児期は家族の支援が必要だが、成長に伴い自立して行えるよう促すことが重要である。  
2. ヘンダーソン14項目: 
   - **14 (学ぶ):** セルフケアでは病気の知識・技術を学習する必要がある。  
   - **8 (清潔):** 注射時や測定時に衛生管理が必要。  
   - **9 (安全):** 誤投与や低血糖などを防ぎ、安全に治療を継続する。  
3. 因果: 不足する指導や支援→セルフケア行動の停滞→血糖コントロール不良・合併症リスク増大。  
4. 看護: 
   - **OP:** 血糖測定や注射など患者の自己管理行動と理解度を観察する。心理的抵抗や不安を確認する。  
   - **TP:** 患者ができることを積極的に参加させ、自立性を促す。達成した内容は褒めて意欲を支援する。  
   - **EP:** 注射・測定・食事の方法と重要性を説明する。低血糖時の対処法や緊急連絡先について指導する。親には見守りと支援のポイントを教育する。  
5. 出典: 中村伸枝編著『1型糖尿病のこどもと家族の生活 改訂3版』(2022)。  
6. 範囲: 1型糖尿病など自己管理が必要な慢性疾患全般にあてはまる概念。精神発達障害などでセルフケアが難しい場合は個別対応が必要。  

# Topic: 「診断名」
1. 内容: 診断名は、医師が患者の症状や検査結果から総合的に判断して決定する病気の名称である（未確認）。診断名により治療方針や看護計画が定まる。  
2. ヘンダーソン14項目: **10 (コミュニケーション):** 正確な診断名の説明は医療者と患者・家族の意思疎通に関わる。 **14 (学ぶ):** 患者自身が診断名を理解し、病気について学ぶ必要がある。  
3. 因果: 不明。  
4. 看護: OP: 患者・家族の診断名理解度や心理状態（動揺、拒否感など）を観察する。 TP: 診断内容を平易に説明し、不安に対しては共感的な支援を行う。 EP: 診断名の意味・経過・治療の必要性を丁寧に教育し、質問に答える。  
5. 出典: 未確認。  
6. 範囲: 診断名はすべての疾病に共通する概念であり、特定の疾病に限定されない。  

# Topic: 「在宅療法」
1. 内容: 在宅療法は、退院後に自宅で継続して行う治療・管理を指す（未確認）。1型糖尿病では退院後も自宅でインスリン注射や血糖測定、食事・運動管理などを継続することが含まれる（未確認）。  
2. ヘンダーソン14項目: **2 (飲食):** 自宅での食事管理が必要。 **9 (安全):** 在宅での低血糖・高血糖や機器トラブルに注意。 **10 (コミュニケーション):** 在宅療養で自立性が増すため、看護者・家族との連携とコミュニケーションが重要。  
3. 因果: 不明。  
4. 看護: OP: 自宅での生活状況（血糖記録、服薬・注射状況、家族支援の程度）を評価。 TP: 退院計画書に沿って治療・検査を継続し、訪問看護や外来フォローアップを調整する。 EP: 家庭でのインスリン投与方法、低血糖時の対応、自己管理計画を指導し、生活リズム調整を助言する。  
5. 出典: 未確認。  
6. 範囲: 主に退院後自宅で療養する患者に該当。入院中の治療や通院のみの管理には該当しない。  

# Topic: 「嘔吐下痢症」
1. 内容: 嘔吐下痢症（急性胃腸炎）は主にウイルス感染による小児の胃腸炎で、ロタウイルス・ノロウイルスなどが原因となる。激しい嘔吐に続いて水様性下痢が起こり、38〜39℃の発熱や鼻汁・咳などの軽い風邪症状を伴うことが多い。大量の嘔吐下痢により急速に脱水をきたしやすい。  
2. ヘンダーソン14項目: **3 (排泄):** 頻回の嘔吐・下痢があるため、水分・電解質喪失に注意し排便・排尿量を観察。 **7 (体温調節):** 高熱を伴うことがあるため体温と発汗を観察。 **9 (安全):** 激しい脱水・電解質異常を起こす危険があるため、循環動態や意識レベルを観察し水分補給に注意。  
3. 因果: ウイルス感染→胃腸粘膜炎症→激しい嘔吐・水様下痢→急激な脱水・電解質異常発生。  
4. 看護: 
   - **OP:** 嘔吐・下痢量、摂取水分量、尿量など脱水徴候（皮膚乾燥・眼球陥凹・体重減少）の観察とバイタルサイン測定。  
   - **TP:** 経口補水液または生理食塩液で急速に水分・電解質を補充し、脱水を防ぐ。必要に応じて解熱剤や制吐剤を投与する。乳糖不耐症を防ぐため乳糖除去ミルクを使用する。  
   - **EP:** 家庭でのこまめな水分補給（口当たりのよい補水飲料）と乳幼児の離乳食から徐々に食事に戻す方法を指導する。嘔吐下痢の際の手洗い徹底など感染予防を教育し、脱水症状（ぐったり、尿量減少）が見られたら早期受診を指導する。  
5. 出典: 信愛記念病院小児科『「冬の嘔吐下痢症」の家庭看護』（年不明）。  
6. 範囲: 主にウイルス性胃腸炎に関する知識で、細菌性下痢症や食中毒・メンブレン異常など他の原因による嘔吐下痢とは区別して扱う。  

# Topic: 「インスリン」
1. 内容: インスリンは膵β細胞から分泌されるホルモンで、血糖値を下げ、脂肪・タンパク質代謝を調節する。糖尿病治療では注射薬として補充し、作用発現時間に応じて超速効型、速効型、中間型、長時間型などに分類される。注射により血糖値を強力に下げるため、低血糖に注意が必要。  
2. ヘンダーソン14項目: **2 (飲食):** インスリンは血糖を利用可能にし正常な栄養摂取を支える。 **9 (安全):** 副作用の低血糖や過量投与によるショックに注意し、安全な投与管理を行う。  
3. 因果: インスリン投与不足→高血糖およびケトーシス・ケトアシドーシス。過剰投与や食事不足→低血糖を引き起こし意識障害等を来す。  
4. 看護: 
   - **OP:** 血糖値と末梢神経症状（冷や汗・振戦・動悸など）を観察し、低血糖や高血糖の徴候を確認する。注射部位の皮膚状態（紅斑・硬結）も観察する。  
   - **TP:** 注射薬は処方通り正しく調整し、定められた時刻に投与する。混合や稀釈が必要な場合は正確に行い、注射針の長さ・角度に注意して投与する。緊急時に備えブドウ糖などを準備する。  
   - **EP:** インスリン作用時間・副作用（低血糖症状）について患者・家族に説明し、低血糖時の応急対処（冷や汗・震えに気づいたら砂糖摂取）を指導。注射部位ローテーションの方法と血糖自己測定の重要性を教育する。  
5. 出典: 岸田裕治「インスリンの副作用と注意点」(2026), 日本糖尿病学会『糖尿病治療ガイドライン2024』等より抜粋。  
6. 範囲: インスリン療法を行う糖尿病患者に適用される知識。経口血糖降下薬のみの2型糖尿病や健康な人には当てはまらない。  

# Topic: 「糖尿病性ケトアシドーシス」
1. 内容: 糖尿病性ケトアシドーシス（DKA）は、インスリン絶対欠乏によって生じる急性代謝性合併症で、高血糖・高ケトン血症・代謝性アシドーシス・脱水を特徴とする。1型糖尿病でインスリン中断や感染などが引き金となり、脂肪分解が亢進してケトン体（アセト酢酸、β-ヒドロキシ酪酸）が蓄積し代謝性アシドーシスに至る。典型的症状は口渇・多飲・多尿、全身倦怠感、悪心・嘔吐、腹痛、クスマウル呼吸、アセトン臭、意識障害などである。  
2. ヘンダーソン14項目: **1 (呼吸):** 重度のアシドーシスによるクスマウル呼吸で呼吸パターンが変化するため呼吸数・様式を観察。 **3 (排泄):** 高血糖・ケトン尿による多尿や嘔吐で脱水が進むため、水分・尿量を観察する。 **9 (安全):** 命に関わる重篤な状態のため、早期治療が必要である。  
3. 因果: インスリン欠乏→脂肪分解・ケトン産生の亢進→ケトン体蓄積・代謝性アシドーシス→浸透圧性利尿・電解質異常・脱水→ショック・意識障害に至る。  
4. 看護: 
   - **OP:** 血糖値・尿ケトン体・血液ガス（pH、HCO₃⁻）を測定し、血清電解質（特にK⁺）の動向を観察する。呼吸状態（クスマウル呼吸）と意識レベルを頻回に評価する。  
   - **TP:** 生理食塩水による急速輸液で循環血液量を回復させ、インスリンを持続静注して血糖降下を図る。同時に血清カリウムが低下するため、K⁺補正を行う。  
   - **EP:** インスリン療法の中断・不足がDKAの原因となること、発熱や感染時の自己管理（「シックデイ」）の重要性を説明する。DKAの症状（脱水、傾眠など）を家族に認識させ、早急に受診するよう指導する。  
5. 出典: 日本糖尿病学会『糖尿病診療ガイドライン2024』, 「ポンコツ看護師の勉強ログ」(2025)。  
6. 範囲: 1型糖尿病患者の急性合併症に特化した知識。高血糖高浸透圧症候群（HHS）や乳酸アシドーシスとは異なる病態であり、ケトアシドーシス特有の管理を要する。  

# 追加提案
- **血糖自己測定**: 血糖コントロールの基本であり、低血糖・高血糖を早期に発見するために重要。測定法・記録方法の指導が必要。  
  *なぜ必要か*: セルフケアやインスリン調整に不可欠な基礎データとして重要なため。
