## Part B: cross-cutting areas (care-plan knowledge rows, Henderson centre, observations)
- 成人急性期: 無気肺/肺炎, SSI, イレウス, せん妄, DVT/PE. Henderson 1,3,4,7,8,9. 麻酔・疼痛・不動→浅呼吸/血栓/腸運動低下, 創→感染. 「手術+不動+下肢腫脹/疼痛」「DVTリスク+突然の呼吸困難」は高優先度の組合せ (日本循環器学会2025 PE/DVT GL).
- 心不全: 呼吸困難だけでなく体重・浮腫・体液量・活動耐容能・服薬・増悪兆候の教育をひとまとめ (日本循環器学会/日本心不全学会2025改訂).
- COPD: 息切れ→活動制限→廃用→さらに耐容能低下の循環 (日本呼吸器学会 COPD GL第6版2022).
- CKD: eGFR・蛋白尿・血圧・電解質・貧血・体液状態・薬物排泄を横断 (日本腎臓学会 CKD診療ガイド2024/GL2023).
- 脳卒中: 意識・運動麻痺・嚥下・構音・認知・排泄・転倒・再発予防へ多値展開 (脳卒中治療GL2021〔改訂2025〕).
- パーキンソン病: 運動症状に加え嚥下・便秘・起立性低血圧・睡眠など非運動症状 (日本神経学会2018, 鮮度フラグ).
- がん看護: 倦怠感は疼痛・貧血・不眠・栄養状態・筋力低下・感染・脱水・電解質異常・悪液質・不安など複数原因 → 原因候補を横断検索 (国立がん研究センター). オピオイド使用時は疼痛だけでなく便秘・悪心・鎮静・呼吸を必須リンク.
- 老年: 大腿骨近位部骨折は4だけでなく4+5+9+3+14; 高齢者の薬剤は転倒・認知・QOL (日本老年医学会 高齢者の安全な薬物療法GL2025).
- 小児: 小児喘息 (JPGL2023); 年齢別正常値・発達段階・家族教育を属性に持たせる.
- 精神: うつ・統合失調症・不安・コミュニケーション; Henderson 5,9,10,12,13,14; 気分・思考・睡眠・安全・社会機能. 症状から診断名を逆推定しない.
- 薬: 降圧薬・利尿薬・抗凝固薬・ステロイド・オピオイド・インスリン・睡眠薬; 「薬剤→作用→有害事象→観察」を明示.
- 検査・バイタル: BP,HR,RR,SpO2,T,血糖,CBC,腎・肝・電解質; 単一値より推移・症状・薬剤との関係.

## Common nursing problems: causal chain and OP/TP/EP
- 活動耐性低下: 心肺機能低下/貧血/疼痛 → 酸素供給または活動効率低下 → 労作時症状 → 活動量低下 → 廃用. OP HR/BP/RR/SpO2・息切れ・疲労・活動量; TP 段階的活動・休息・リハ連携; EP 負荷調整・症状時中止; 不足: 安静時データだけで判断.
- 感染リスク: 皮膚粘膜バリア破綻/免疫低下/侵襲的デバイス → 微生物侵入機会増加 → 局所感染 → 全身感染. OP T・局所徴候・WBC・デバイス; TP 手指衛生・創/デバイス管理; EP 感染徴候の自己観察; 不足: 発熱だけを監視.
- 転倒リスク: 筋力低下/視力低下/鎮静薬/起立性低血圧 → バランス・判断低下 → ふらつき → 転倒 → 外傷. OP 歩行・筋力・視力・起立時症状・薬剤; TP 環境整備・移動介助; EP ナースコール・補助具; 不足: 薬剤/起立性低血圧を無視.
- 褥瘡リスク: 不動+圧迫/ずれ+湿潤/栄養不良 → 局所組織負荷 → 組織障害 → 皮膚損傷. OP 皮膚・圧迫・湿潤・栄養・可動性; TP 体位・除圧・皮膚管理; EP 体位変換; 不足: 皮膚だけで栄養を見ない.
- 栄養摂取不足: 食欲低下/嚥下障害/悪心/疼痛 → 摂取低下 → エネルギー・蛋白不足 → 体重/筋量低下 → 回復遅延. OP 摂取・体重・嚥下・悪心・口腔; TP 食形態・症状調整・多職種連携; EP 少量頻回等; 不足: Alb単独で判定.
- 排尿障害: 神経障害/閉塞/薬剤/不動 → 膀胱排出障害 → 残尿・尿閉/失禁 → 不快・感染. OP 尿量・回数・残尿感・膀胱症状; TP 排尿環境・必要時測定; EP 水分・排尿記録; 不足: 尿量のみで評価.
- 疼痛: 組織損傷/炎症/神経障害 → 侵害受容 → 疼痛 → 睡眠・活動低下 → QOL低下. OP 強度+部位+性状+機能影響; TP 薬物/非薬物・再評価; EP 早期申告・薬の使い方; 不足: 投薬後の再評価欠落.
- 不安: 疾患・予測不能性/情報不足 → 脅威認知 → 不安 → 睡眠・集中・意思決定低下 → セルフケア影響. OP 内容・強さ・睡眠・理解度・支持; TP 傾聴・情報整理・意思決定支援; EP 質問・相談方法; 不足: 「不安あり」で終了.
- OP/TP/EP は「何を見るか」だけでなく「いつ・何をもって悪化/改善とするか」を記録できる構造に.

## Lab nodes (minimum set) and reading rules
CBC/Hb/Plt, CRP, Na/K, BUN/Cr/eGFR, AST/ALT/ALP/γ-GTP/ビリルビン, Alb, 血糖/HbA1c, 凝固系, 尿検査 — 症状・疾患・薬剤から双方向に検索可能に。基準範囲は施設基準を優先(全国共通の正常値として固定しない)。基準範囲外=疾患確定ではない。腎機能→フルマリン等の薬剤安全、血糖→糖尿病・インスリン、Hb→出血・子宮筋腫・がん、肝胆道系→膵頭部癌・肝転移。変化量・前回値・患者背景・薬剤・症状を併せて評価.

## Design proposals
1. 薬剤: 「薬そのもの」と「薬から起きる観察項目」を分ける。ブランド名-一般名-剤形-作用時間を独立フィールドに。必ず確認する有害事象を構造化(フルマリン: アナフィラキシー・腎肝・血球・重篤な下痢; オキシコドン: 呼吸・意識・便秘・悪心・尿閉; インスリン: 低血糖).
2. 症状→診断の推論には信頼度を持たせる(発赤→SSI確定ではなく、発赤+創部+熱感/膿性排液/発熱でSSI評価優先度上昇).
3. 否定・既往・時制を別属性に(胸痛なし/陳旧性心筋梗塞/術後/手術予定/硬膜外抜去済み).
4. 診断確定・疑い・症状・リスクを分ける.
5. 検査値は基準値より変化量と文脈.
6. 高リスク組合せを単語単位より上位に(オピオイド+呼吸数低下/傾眠; インスリン+摂取不良/低血糖; 硬膜外抜去+抗凝固薬+神経症状; 手術創+発赤+膿性排液/発熱; 不動+片側下肢腫脹; 膵頭部がん+黄疸+発熱).
7. 未知語(今検査)は unknown_term・前後文要求・human reviewに.
8. 出典には版・年月・有効期限(source_year/edition/checked_at/next_review)を持たせる。現行版メモ: 大腸癌2026, 心不全・PE/DVT 2025, 高血圧2025, 胃癌第7版2025, 膵癌2025, 大腿骨頚部/転子部骨折2021第3版(次版2026年12月予定).
